## 실제 API와 브라우저 통합 검사

`scripts/owner-flow-e2e.mjs`는 별도 새 시연 DB, 실제 Spring 서버, 실제 React 웹을 Chromium에서 사용합니다. 일반적인 반복 실행은 기존 데이터를 초기화하지 않으므로 새 시연 DB를 준비해야 합니다.

## 실기기와 실자료에서 남은 확인

- 새 `expo-document-picker` 네이티브 모듈을 포함한 Android APK 다시 빌드·설치.
- 실제 폰에서 파일 선택, 날짜 입력, 구매 사이트 이동·복귀, 입고 처리 확인.
- Firebase 서버 서비스 계정 설정 후 실제 `UPLOAD`·`OPENING` 푸시 수신·탭·로그인 후 상세 복귀 확인.
- 영업 시작 3시간 전 실제 스케줄 발송 확인. 시연 강제 트리거는 실제 시간 대기 검증을 대신하지 않음.
- 실제 매장 메뉴 1인분 소모량·초기 재고·POS 자료·포장 크기·공공 가격 자료 확인.

외부 결제나 실제 주문은 수행하지 않습니다. 브라우저 검사의 외부 상품 카드와 구매 링크 페이지는 검증용 응답을 사용하며, 구매 기록·배송 입고·판매 차감 API는 실제 서버를 사용합니다. 기존 레시피 자료 68개 메뉴는 온보딩용 기본자료이며 실제 1인분 소비량으로 검증된 자료가 아닙니다.
